# Smart File Organizer 📁

A Python automation project that automatically organizes files in a folder based on their file types.

---

## 🚀 What this project does

This program scans a folder (like Downloads) and automatically:

- Sorts images into an Images folder
- Sorts documents into a Documents folder
- Sorts videos into a Videos folder
- Sorts music into a Music folder
- Sorts archives into an Archives folder
- Moves unknown files into an Others folder

It also:
- Logs all actions into a log file
- Shows a summary report of all files moved
- Handles errors without crashing

---

## 🛠️ Technologies used

- Python 3
- os module (file handling)
- shutil module (moving files)
- datetime module (logging timestamps)
